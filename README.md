# RAVI Lab — NIT Agartala Homepage

Responsive single-page website for RAVI Lab — Rheology and Advanced Visualization of Interfaces — led by Dr. Ravi Prakash, Department of Chemical Engineering, NIT Agartala.

## Files
- `index.html` — homepage structure and content
- `style.css` — complete responsive styling
- `script.js` — mobile navigation, reveal effects, sticky header, back-to-top
- `assets/Ravi-Prakash-CV.pdf` — CV used by the "View CV" button
- `assets/RAVI-Lab-logo.png` — RAVI Lab website logo

## Publish on GitHub Pages
1. Upload all files and the `assets` folder to the root of:
   `RaviLab-NITA/RaviLab-NITA.github.io`
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. The site should publish at:
   `https://RaviLab-NITA.github.io`
